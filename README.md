## 🌐 Live Demo

https://sentiment-model-jkhp36kdppzthnifjv9bfh.streamlit.app

## Project Overview

This project predicts whether a piece of text expresses a positive or negative sentiment using a machine learning model.

## Features

- Predicts sentiment from text
- Text preprocessing
- Machine learning-based classification
- Easy to run locally

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- TensorFlow
- OpenCV (if used)
- VS Code

## Installation

1. Clone the repository

```bash
git clone https://github.com/rc4039647-glitch/sentiment-model.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the project

 ```bash
python sentiment_model.py
```

## Example

**Input:**

```
I really enjoyed this movie.
```

**Output:**

```
Positive
```
